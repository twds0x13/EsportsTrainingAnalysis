# 电竞训练分析系统需求文档

## 1. 文档说明

### 1.1 编写目的

本文档描述电竞训练分析系统的产品目标、用户对象、核心功能、训练规则、数据结果和使用约束，为后续界面设计、开发实现和验收测试提供统一依据。

### 1.2 项目定位

电竞训练分析系统是一款面向电竞选手、半职业选手和电竞爱好者的桌面训练软件。系统通过固定靶、移动靶和反应靶训练，记录用户的点击行为与瞄准表现，提供可查询的原始训练数据、个人历史记录和分项排行榜。

系统以训练过程的可量化记录为核心，不使用综合评分替代原始数据。用户可以根据具体指标了解自己的反应速度、点击节奏和跟枪稳定性。

### 1.3 交付范围

- 桌面端应用，支持 Windows 和 Linux。
- 用户账号登录、训练 session、训练数据记录、历史查询和排行榜。
- 九宫格固定靶、移动靶、反应靶三种训练项目。
- 护眼与训练时长管理功能。
- 项目源代码以 MIT License 开源。

## 2. 用户与使用条件

### 2.1 目标用户

- 电竞职业选手；
- 电竞半职业选手；
- 电竞爱好者；
- 需要查看训练数据的教练或训练管理者。

### 2.2 账号要求

1. 用户必须使用账号登录后才能进入训练功能。
2. 系统不提供游客训练模式。
3. 训练 session、历史成绩和排行榜数据与用户账号关联。
4. 用户开始训练时必须保持互联网连接。

### 2.3 网络中断

1. session 开始后发生网络断连，不中断当前训练。
2. 用户可以在断网状态下完成训练。
3. 训练完成后，该成绩标记为“本地成绩”。
4. 用户恢复联网后，可以手动上传本地成绩。
5. 网络断连造成的本地成绩不属于无效 session。

## 3. 核心概念

### 3.1 训练 session

一次从训练开始到训练结束的完整训练过程称为一个 session。每个 session 独立保存训练项目、训练参数、训练结果、状态和时间信息。

### 3.2 有效训练时间

有效训练时间只包含用户实际进行训练的时间。以下阶段不计入有效训练时间：

- 训练开始前的准备阶段；
- 倒计时准备阶段；
- 暂停阶段；
- 训练结束后的结果展示阶段；
- 其他不属于实际训练的阶段。

### 3.3 session 状态

系统至少需要区分以下状态：

- 进行中；
- 有效成绩；
- 本地成绩；
- 无效成绩；
- 已上传。

网络断连产生的本地成绩与无效成绩分别记录。前者表示训练有效但暂未完成云端上传，后者表示本次训练过程不具备有效成绩资格。

## 4. 训练通用需求

### 4.1 训练项目选择

系统提供以下训练项目：

1. 九宫格固定靶；
2. 移动靶；
3. 反应靶。

### 4.2 session 结束方式

每次开始训练前，用户必须在以下两种结束方式中选择一种：

- **倒计时模式**：训练时间范围为 30 秒至 300 秒；
- **目标数量模式**：目标数量范围为 20 至 1000。

系统不提供无限时长训练。

### 4.3 训练参数

所有训练项目支持配置以下参数：

- 目标尺寸；
- 训练区域位置；
- 训练区域大小。

上述参数具有取值范围，具体范围由后续产品配置确定。

三种训练项目还可以根据自身规则配置移动速度、隐藏时间、轨迹类型和采样频率等参数。

### 4.4 视角与移动

1. 用户可以自由转动视角。
2. 用户不能使用角色或场景移动功能。
3. 训练成绩只反映瞄准、跟踪和点击表现。

### 4.5 暂停

1. 用户可以暂停当前训练。
2. 暂停期间停止有效训练时间计时。
3. 暂停期间停止训练数据采样。
4. 只要 session 发生过暂停，本次训练成绩即记为无效。
5. 无效 session 需要记录具体失效原因。

## 5. 训练项目需求

### 5.1 九宫格固定靶

1. 训练区域划分为九个固定位置。
2. 圆形目标从九个位置中随机刷新。
3. 用户命中当前目标后，系统立即刷新下一个目标。
4. 下一次刷新时排除上一枪命中的位置。
5. 系统同时排除当前被占用的位置。
6. 目标从剩余位置中随机选择。
7. session 按用户选择的倒计时或目标数量结束。

### 5.2 移动靶

1. 目标在训练区域内持续移动。
2. 用户需要使用鼠标持续跟踪目标并点击。
3. 目标被点击后不消失，继续移动。
4. 系统支持以下轨迹类型：
   - 随机折线；
   - 固定折线；
   - 随机贝塞尔曲线。
5. 用户可以配置目标移动速度。
6. 准心覆盖率按照固定采样频率统计。
7. 准心覆盖率根据采样点计算：

   ```text
   准心覆盖率 = 位于目标覆盖范围内的采样点数 / 总采样点数
   ```

8. 目标数量模式下，session 在有效点击次数达到设定值时结束。
9. 倒计时模式下，session 在倒计时结束时结束。

### 5.3 反应靶

1. 目标在整个训练区域内随机出现。
2. 目标出现前可以设置隐藏时间。
3. 隐藏时间默认值为 0 毫秒。
4. 系统记录目标出现时间和用户点击时间。
5. 每次反应耗时按以下规则计算：

   ```text
   反应耗时 = 鼠标点击时间 - 目标出现时间
   ```

6. session 按用户选择的倒计时或目标数量结束。

## 6. 点击数据与结果

### 6.1 点击分类

系统将点击分为两类：

- **有效点击**：点击命中当前目标；
- **无效点击**：未命中目标的全部点击。

系统不再对无效点击进行进一步分类。

### 6.2 通用点击指标

所有训练项目均记录并展示以下指标：

- 全部点击次数；
- 有效点击次数；
- 无效点击次数；
- 全部点击频率；
- 有效点击频率；
- 有效点击率。

统一计算规则如下：

```text
全部点击频率 = 全部点击次数 / 有效训练时间
有效点击频率 = 有效点击次数 / 有效训练时间
有效点击率 = 有效点击次数 / 全部点击次数
无效点击次数 = 全部点击次数 - 有效点击次数
```

### 6.3 项目专属指标

九宫格固定靶至少记录：

- 目标命中次数；
- 目标刷新位置；
- 每次点击间隔；
- 每次目标完成耗时。

移动靶至少记录：

- 准心覆盖率；
- 有效点击次数；
- 全部点击频率；
- 有效点击频率；
- 有效点击率；
- 无效点击次数。

反应靶至少记录：

- 目标出现时间；
- 鼠标点击时间；
- 每次反应耗时；
- 平均反应耗时；
- 最快反应耗时。

### 6.4 综合评分

系统当前不计算手速、反应力、稳定性等综合评分，直接展示原始训练数据。

## 7. session 结果与历史记录

### 7.1 结果保存

1. 每个 session 独立保存训练结果。
2. 历史记录至少包含：
   - 训练项目；
   - 结束方式；
   - 训练参数；
   - 开始时间和结束时间；
   - 有效训练时间；
   - 原始训练指标；
   - session 状态；
   - 失效原因；
   - 上传状态。
3. 用户可以按日期查询历史成绩。
4. 系统保留用户的历史成绩记录，不只保留个人最高成绩。

### 7.2 无效 session

1. 无效 session 保存在本地个人历史记录中。
2. 无效 session 必须标记具体失效原因。
3. 无效 session 不上传服务器。
4. 无效 session 不作为有效训练记录参与排行榜。

### 7.3 成绩上传

1. session 结束后，系统一次性处理本次训练结果。
2. 网络正常时，标准模式成绩在 session 结束后上传服务器。
3. 网络断连时，训练结果保存为本地成绩。
4. 用户恢复联网后，可以手动上传本地成绩。
5. 上传成功后，系统更新成绩的上传状态。

## 8. 标准模式与排行榜

### 8.1 标准模式

1. 三种训练项目分别设置独立的标准模式。
2. 标准模式参数由服务器统一分发。
3. 标准模式固定以下参数：
   - 目标尺寸；
   - 训练区域位置；
   - 训练区域大小；
   - 靶子移动速度；
   - 隐藏时间；
   - 采样频率；
   - 倒计时或目标数量参数。
4. 用户修改任意标准参数后，该 session 记为本地成绩。
5. 标准模式成绩需要记录对应的标准配置版本。

### 8.2 排行榜类型

系统为每一类原始指标分别提供独立排行榜，不设置综合评分、统一主指标或次级排序。

排行榜包括但不限于：

- 目标数量排行榜；
- 训练用时排行榜；
- 全部点击频率排行榜；
- 有效点击频率排行榜；
- 有效点击率排行榜；
- 平均反应耗时排行榜；
- 准心覆盖率排行榜。

### 8.3 排行榜范围

- 全局排行榜只接收标准模式成绩；
- 非标准参数成绩统一记为本地成绩；
- 网络断连产生的成绩统一记为本地成绩；
- 本地成绩只进入本地排行榜；
- 无效 session 只保留在本地历史记录中。

### 8.4 排序方向

- 目标数量：数值越高，排名越靠前；
- 全部点击频率：数值越高，排名越靠前；
- 有效点击频率：数值越高，排名越靠前；
- 有效点击率：数值越高，排名越靠前；
- 准心覆盖率：数值越高，排名越靠前；
- 训练用时：数值越低，排名越靠前；
- 平均反应耗时：数值越低，排名越靠前。

倒计时模式和目标数量模式分别在对应的独立排行榜中使用以下排序数据：

- 倒计时模式按完成的目标数量排序；
- 目标数量模式按完成目标所用的训练时间排序。

## 9. 护眼与训练时长管理

护眼功能用于管理用户连续训练时间，并提醒用户进行有效休息。

### 9.1 休息规则

1. 默认每累计训练 30 分钟，要求用户休息至少 5 分钟。
2. 用户可以调整休息触发频率，范围为 15 分钟至 60 分钟。
3. 软件关闭时间超过 5 分钟时，计为有效休息，并重置累计训练时间。
4. 软件关闭时间不超过 5 分钟时，不重置累计训练时间。
5. 休息状态在应用重启后保持连续。

### 9.2 护眼界面

达到休息条件后，系统显示护眼休息界面，并引导用户完成规定的休息时间。

护眼界面在训练 session 结束时的接管时机，需要结合当前统一采用的有限时长训练规则进一步确定。

## 10. 质量与使用要求

### 10.1 数据一致性

- session 的训练配置、原始指标、状态和失效原因应保持一致；
- 网络断连不应改变已经完成的训练数据；
- 无效 session 与本地成绩应在历史记录中明确区分；
- 标准模式成绩应能够对应到具体标准配置。

### 10.2 训练操作

- 训练过程中应保持目标刷新、点击判定和数据记录的一致性；
- 暂停后不继续累计训练时间；
- 暂停后不继续采样；
- 训练结果应清楚展示本次 session 是否具备排行榜资格。

## 11. 待确认事项

以下内容不影响当前需求文档的主体结构，但需要在界面设计、数据设计和验收测试前确定：

1. 目标尺寸、训练区域位置和训练区域大小的具体取值范围；
2. 固定靶和反应靶在目标数量模式下的目标计数规则；
3. 移动靶采样频率、移动速度和轨迹参数的具体范围；
4. 无效 session 的完整失效原因列表；
5. 无效 session 是否允许用户查看逐次点击明细；
6. 护眼界面与有限时长 session 结束流程的衔接规则；
7. 排行榜中相同指标的并列显示规则。
